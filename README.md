# Kids School - L1B11A2

A responsive **Kids School** landing page built with **HTML5 and CSS3**. The website presents a colorful and engaging educational interface with school information, curriculum sections, student stories, navigation, and contact details.

The project focuses on clean frontend structure, responsive layouts, CSS styling, and converting a visual design into a functional static website.

## Overview

Kids School is a static educational website designed for a children's learning institution.

The website includes:

* School navigation
* Hero section
* Enrollment call-to-action
* Standard curriculum
* Student stories
* Story cards
* School information
* Social media links
* Responsive frontend layout

The design uses a colorful visual style suitable for a children's education platform.

## Features

### Navigation

The navigation bar includes:

* School logo

### Hero Section

The hero section introduces the school with:

### Standard Curriculum

The curriculum section presents three educational levels:

* Kinder

Each curriculum card contains:

### Student Stories

The Stories section showcases student and classroom-related content through:

* View All button

### Footer

The footer contains:

* Kids Education branding
* School description
* About School navigation
* Social media icons

## Getting Started

### Prerequisites

No framework, package manager, or backend is required.

You only need:

* A modern web browser
* A code editor such as VS Code

### Clone the Repository

```bash
git clone https://github.com/mrshanshuvo/kids-school.git
```

Navigate to the project:

```bash
cd kids-school
```

### Run the Project

Open `index.html` directly in your browser.

For a better development experience, use the **Live Server** extension in VS Code.

## Styling

The website styling is maintained in:

```text
styles/style.css
```

The project uses:

* Flexbox for major layouts
* CSS Grid for story cards
* Custom colors
* Rounded cards
* Typography hierarchy
* Background images
* Responsive styling
